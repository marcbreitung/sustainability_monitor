======================
Standalone Web Components
======================

The metric elements can be embedded without the TYPO3 plugin. Include the
module for each element you use:

..  code-block:: html

    <script type="module" src="/typo3conf/ext/sustainability_monitor/Resources/Public/JavaScript/sm-number-of-requests.js"></script>
    <sm-number-of-requests label="Number of Requests"></sm-number-of-requests>

In a Composer installation, use the public asset URL generated by your TYPO3
installation for ``EXT:sustainability_monitor/Resources/Public/JavaScript/``.
The plugin itself adds these modules automatically.

Properties
==========

All properties can be set as HTML attributes. Stencil maps camelCase
properties to kebab-case attributes, for example ``highlightClass`` becomes
``highlight-class`` and ``ariaLabel`` becomes ``aria-label``. String
properties can also be set through JavaScript using their camelCase property
names. Boolean properties use the presence of the attribute as their enabled
value, so use ``highlight`` to enable highlighting.

``sm-largest-contentful-paint``
-------------------------------

Displays the page's Largest Contentful Paint (LCP) value. The value is
formatted in seconds and is updated from the browser's
``PerformanceObserver`` API. If highlighting is enabled, the component can
scroll to and briefly mark the element reported by the LCP entry.

``label``
    *Type:* string

    *Attribute:* ``label``

    *Default:* ``Largest Contentful Paint``

    Text displayed next to the metric value. Set it to an empty string to hide
    the label and its optional action button.

``info``
    *Type:* string

    *Attribute:* ``info``

    *Default:* ``The Largest Contentful Paint is calculated based on the
    startTime property of the last entry in the PerformanceObserverEntryList.``

    Tooltip text for the label. Set it to an empty string to display the label
    without a tooltip.

``locale``
    *Type:* string

    *Attribute:* ``locale``

    *Default:* ``de-DE``

    BCP 47 locale passed to ``Intl.NumberFormat`` when formatting the value.
    Use a locale supported by the browser, such as ``en-US`` or ``de-DE``.

``highlight``
    *Type:* boolean

    *Attribute:* ``highlight``

    *Default:* ``false``

    Enables the button for locating the LCP element. The button is rendered
    only when this property is enabled and remains disabled until an LCP entry
    with an element is available.

``highlight-class``
    *Type:* string

    *Property:* ``highlightClass``

    *Default:* ``highlighted``

    CSS class added to the LCP element for two seconds after the button is
    activated. Define this class in the containing document.

``highlight-label``
    *Type:* string

    *Property:* ``highlightLabel``

    *Default:* ``?``

    Visible button text for the highlight action.

``aria-label``
    *Type:* string

    *Property:* ``ariaLabel``

    *Default:* ``Show Largest Contentful Paint Element``

    Accessible name of the highlight button.

``popover-text``
    *Type:* string

    *Property:* ``popoverText``

    *Default:* ``Click to highlight the largest contentful paint element``

    Text shown in the popover while the highlight button is hovered or
    focused.

``sm-number-of-requests``
-------------------------

Displays the number of resource and navigation entries reported by the
browser's ``PerformanceObserver`` API. The document navigation is counted in
addition to resource entries.

``label``
    *Type:* string

    *Attribute:* ``label``

    *Default:* ``Number of Requests``

    Text displayed next to the metric value. Set it to an empty string to hide
    the label.

``info``
    *Type:* string

    *Attribute:* ``info``

    *Default:* ``The number of requests is calculated based on the number of
    entries in the PerformanceObserverEntryList for resource and navigation
    entries.``

    Tooltip text for the label. Set it to an empty string to display the label
    without a tooltip.

``sm-co2-emission``
-------------------

Displays the estimated CO2 emissions calculated from the page's transferred
data size. The result is formatted in grams.

``label``
    *Type:* string

    *Attribute:* ``label``

    *Default:* ``Co2 Emission``

    Text displayed next to the metric value. Set it to an empty string to hide
    the label.

``info``
    *Type:* string

    *Attribute:* ``info``

    *Default:* ``The Co2 emission is calculated based on the transfered size.``

    Tooltip text for the label. Set it to an empty string to display the label
    without a tooltip.

``locale``
    *Type:* string

    *Attribute:* ``locale``

    *Default:* ``de-DE``

    BCP 47 locale passed to ``Intl.NumberFormat`` when formatting the gram
    value.

``sm-transferred-size``
-----------------------

Displays the amount of data transferred by the page, including the navigation
entry and resource entries reported by the browser. The result is formatted
in kilobytes.

``label``
    *Type:* string

    *Attribute:* ``label``

    *Default:* ``Transferred Size``

    Text displayed next to the metric value. Set it to an empty string to hide
    the label.

``info``
    *Type:* string

    *Attribute:* ``info``

    *Default:* ``The Transferred Size.``

    Tooltip text for the label. Set it to an empty string to display the label
    without a tooltip.

``locale``
    *Type:* string

    *Attribute:* ``locale``

    *Default:* ``de-DE``

    BCP 47 locale passed to ``Intl.NumberFormat`` when formatting the kilobyte
    value.

Example with custom text
========================

..  code-block:: html

    <sm-largest-contentful-paint
        label="LCP"
        info="Time until the largest visible element is painted"
        highlight
        highlight-class="metric-highlight"
        highlight-label="Show element"
        aria-label="Show the largest contentful paint element"
        popover-text="Select to locate the measured element">
    </sm-largest-contentful-paint>

Styling
=======

The components expose these shadow parts for styling with ``::part()``:

* ``container``
* ``label``
* ``value``
* ``popover`` and ``button`` on the LCP component

For example:

..  code-block:: css

    sm-number-of-requests::part(value) {
        color: #166534;
        font-variant-numeric: tabular-nums;
    }
