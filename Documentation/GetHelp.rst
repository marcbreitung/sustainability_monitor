=================
Where to get help
=================

You can get help in the `TYPO3 Slack <https://typo3.org/community/meet/chat-slack>`_.
Ask a question in the official `TYPO3 forum <https://talk.typo3.org/c/typo3-questions/19>`_
or contact the extension author.

When asking for help, include your TYPO3 version, extension version, browser,
enabled metrics, and a concise description of the page and behavior. Do not
include personal data from performance entries.

..  _report-issues:

Report Issues
=============

You can report issues at `https://github.com/marcbreitung/sustainability-monitor/issues <https://github.com/marcbreitung/sustainability-monitor/issues>`_.
